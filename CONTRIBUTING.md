# Contributing to ClimateEnzyme

Thank you for your interest in contributing to the ClimateEnzyme Discovery Pipeline! This project aims to accelerate the discovery of enzymes that can help address environmental challenges like plastic pollution.

## Ways to Contribute

### 1. Report Issues
- Bug reports
- Feature requests
- Documentation improvements
- Questions about usage

### 2. Code Contributions
- Bug fixes
- New features
- Performance improvements
- Tests

### 3. Scientific Contributions
- Validate computational predictions experimentally
- Share experimental data
- Suggest new enzyme families to target
- Improve ranking algorithms

### 4. Documentation
- Improve README and guides
- Add tutorials
- Translate documentation

## Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/ClimateEnzyme.git
   cd ClimateEnzyme
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Create a branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Code Guidelines

### Style
- Follow PEP 8 for Python code
- Use type hints where practical
- Write docstrings for public functions
- Keep functions focused and readable

### Testing
- Add tests for new functionality
- Ensure existing tests pass
- Test with Python 3.10+

### Commits
- Write clear commit messages
- Reference issues when applicable
- Keep commits focused

## Pull Request Process

1. Update documentation if needed
2. Add tests for new features
3. Ensure all tests pass
4. Update the README if adding new functionality
5. Submit PR with clear description
